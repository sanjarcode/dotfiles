## Notes for a fresh machine

- Order: install Node (`nvm`) and `uv` first (see `2-apps.md`), then the Claude Code plugin marketplaces, then the `skills` CLI packages, then let the app-bundled ones (ego lite, tldraw) self-register on first install.
- `~/.claude/skills/*` are mostly symlinks into `~/.agents/skills/*` — the real source of truth is `~/.agents/skills` (shared across agent tools, not just Claude Code).
- Check what's currently active any time with: `ls -la ~/.claude/skills/` and `cat ~/.agents/.skill-lock.json`.
