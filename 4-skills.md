## Notes for a fresh machine

- Order: install Node (`nvm`) and `uv` first (see `2-apps.md`), then the Claude Code plugin marketplaces, then the `skills` CLI packages, then let the app-bundled ones (Composio CLI, and previously ego lite/tldraw) self-register on first install.
- `~/.claude/skills/*` was previously mostly symlinks into `~/.agents/skills/*` — **as of 2026-08-02 that's no longer true**: `spec-kitty-cli` now writes real directories (not symlinks) directly into both locations, and `ad-hoc-profile-load`/`codebase-memory` are also real dirs. Only `composio-cli` is still a symlink back to `~/.agents/skills`. `~/.agents/skills` remains the conceptual source of truth for anything that *is* symlinked.
- Check what's currently active any time with: `ls -la ~/.claude/skills/`, `ls -la ~/.agents/skills/`, `cat ~/.agents/.skill-lock.json` (may not exist if nothing from the `skills` CLI is installed), `cat ~/.claude/plugins/installed_plugins.json`, and `cat ~/.claude/plugins/known_marketplaces.json`.
- As of 2026-08-02, rows 2, 3, 8, 11, 12 are **not present** on this machine (previously installed, since removed or never carried over) — treat their install steps as a from-scratch reinstall, not a verification.
